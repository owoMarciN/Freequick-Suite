# Freequick — Merchant App

Flutter Web dashboard for restaurant owners. Manage menus, handle incoming orders, view analytics, and configure restaurant settings. Runs entirely in the browser — no mobile build required.

---

## Setup

This app is part of the Freequick Suite mono repo. Complete the root-level setup first — FVM, `secrets.json`, and `firebase_options.dart` must all be in place before running.

### Required files

```
merchant_app/
├── android/app/google-services.json     # Optional — only needed for Android build
└── lib/firebase_options.dart            # Generated by FlutterFire CLI
```

Generate `firebase_options.dart`:
```bash
cd merchant_app
flutterfire configure --project=YOUR_FIREBASE_PROJECT_ID
```

### Run

```bash
cd merchant_app
fvm flutter pub get
fvm flutter run -d web-server --web-port 8080 --dart-define-from-file ../secrets.json
```

Open `http://localhost:8080` in any browser. The VS Code **Flutter (Debug - Web)** launch config in `.vscode/launch.json` does this automatically.

## Features

- Phone number authentication via Firebase OTP
- Setup checklist with progress bar — hidden only once admin sets restaurant `status: 'Active'`
- Real-time order management with Active / Delivered tabs
- Status picker — restaurant sets orders from Pending to In Progress to Ready
- Menu and item management (write-protected until restaurant is approved)
- Promotions management
- Revenue and order analytics with daily trend charts
- Notification centre for new orders and admin broadcasts
- Restaurant profile settings — logo, banner, address, IBAN
- Join request flow — restaurant goes live only after admin approval
- Full localisation via ARB files with Google Translate integration

## Architecture

```
lib/
├── extensions/            # BrandColors ThemeExtension
├── global/                # currentUid, SharedPreferences helpers
├── l10n/                  # ARB localisation files
├── providers/             # LocalStatsProvider, GlobalStatsProvider
├── screens/               # All dashboard screens
└── widgets/               # OrderTableWidget, NotificationBell, etc.
```

### Routing
Uses `go_router` with a `DashboardShell` wrapping all authenticated screens in a persistent sidebar. Admin users see a separate `AdminDashboardShell` with additional routes.

| Route | Screen |
|---|---|
| `/dashboard/overview` | Stats, setup checklist, recent orders |
| `/dashboard/orders` | Full order stream with status picker |
| `/dashboard/menus` | Menu management |
| `/dashboard/items` | Item management |
| `/dashboard/analytics` | Revenue charts |
| `/dashboard/promotions` | Promotions |
| `/dashboard/notifications` | Notification centre |
| `/dashboard/settings` | Restaurant profile |

## Integrations

### Firebase
- **Auth** — phone OTP
- **Firestore** — orders stream, menus, items, promotions, notifications
- **Storage** — logo and banner uploads
- **Cloud Messaging** — new order push notifications

### Stripe Extension
The merchant app does not interact with Stripe directly. It reads the `paymentMethod` field on order documents (`'cash'` or `'stripe'`) to indicate whether a delivery requires cash collection.

### Google Translate
ARB localisation files are generated using the Google Translate API. Supported languages are configured in `l10n.yaml`.
