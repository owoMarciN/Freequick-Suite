# Freequick — Customer App

Flutter mobile app for customers. Browse restaurants, add items to cart, place orders via cash or card, and track delivery in real time.

---

## Setup

This app is part of the Freequick Suite mono repo. Complete the root-level setup first — FVM, `secrets.json`, and `firebase_options.dart` must all be in place before running.

### Required files

```
customer_app/
├── android/app/google-services.json     # Download from Firebase Console
├── ios/Runner/GoogleService-Info.plist  # Download from Firebase Console
└── lib/firebase_options.dart            # Generated by FlutterFire CLI
```

Generate `firebase_options.dart`:
```bash
cd customer_app
flutterfire configure --project=YOUR_FIREBASE_PROJECT_ID
```

### Run

```bash
cd customer_app
fvm flutter pub get
fvm flutter run --dart-define-from-file ../secrets.json
```

## Features

- Phone number authentication via Firebase OTP
- Restaurant browsing with Algolia-powered instant search
- Category and rating filters
- Cart management with saved and GPS-based delivery addresses
- Cash on delivery and Stripe card payment
- Real-time order tracking with live status timeline
- In-app notification centre with per-category preference controls
- Order history with one-tap reorder
- Dark and light theme support
- Localisation via ARB files with Google Translate integration

## Architecture

```
lib/
├── assistant_methods/     # Cart, address, and payment helpers
├── extensions/            # BrandColors ThemeExtension, l10n extension
├── global/                # SharedPreferences helpers, currentUID
├── l10n/                  # ARB localisation files
├── models/                # Address and data models
├── providers/             # ChangeNotifier state providers
├── screens/               # All UI screens
└── widgets/               # Reusable widgets
```

### State Management

| Provider | Responsibility |
|---|---|
| `TotalAmount` | Cart subtotal, delivery fee, savings from discounts |
| `AddressChanger` | Selected delivery address index |
| `LocaleProvider` | Language selection and theme mode |
| `ThemeProvider` | Dark/light mode with SharedPreferences persistence |

## Integrations

### Firebase
- **Auth** — phone OTP sign-in, session persistence
- **Firestore** — orders, cart, addresses, notifications
- **Storage** — profile photos
- **Cloud Messaging** — order status push notifications
- **Cloud Functions** — `placeCashOrder`, `createPaymentIntent`, `saveFcmToken`

### Stripe
Card payments use the Firebase Stripe Extension. The app calls `createPaymentIntent` (Cloud Function) to get a `clientSecret` based on a server-side quote, then presents the Stripe payment sheet. The order is created server-side by the webhook on payment success.

### Algolia
Restaurant and menu item search. The search screen queries the `restaurants` index filtered by `restaurantStatus:active`. Results are indexed from Firestore via the Algolia Firebase Extension.

### Google Maps
The order details screen shows a live map with the rider's position, restaurant marker, and customer drop-off marker once a rider is assigned.
